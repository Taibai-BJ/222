① API 名称
接口叫什么、点名字可跳转官方文档。
② 简介
这个接口是干什么的（英文原文，保留不翻译以免失真）。
③ 认证方式
用之前要不要"钥匙"：
• 无需认证 = 白嫖直接调
• 需注册密钥 = 注册拿 Key
• 需 OAuth 授权 = 走登录授权
• 需设置浏览器标识 = Header 加 UA
④ HTTPS
连接是否加密传输。是 = 安全；否 = 明文，敏感数据别用。
⑤ CORS
能否在浏览器网页里直接跨域调用。支持 = 前端可直调；不支持 = 要走后端转发；未知 = 没标明。
